#
# 版本与 wheelhouse/ 下的实际轮子文件名一一对应，传递依赖见
# wheelhouse/constraints.txt。任何机器都应解析出同一组版本：
#
#   离线安装：
#     python -m pip install --no-index --find-links wheelhouse \
#       setuptools wheel -c wheelhouse/constraints.txt -r requirements.txt
#
#   联网复现下载（平台参数按目标环境替换，见 tools/download_wheels.sh）：
#     python -m pip download -d wheelhouse --only-binary=:all: \
#       --platform manylinux_2_28_x86_64 --python-version 311 \
#       --implementation cp --abi cp311 \
#       -c wheelhouse/constraints.txt -r requirements.txt
#
# 目标解释器：CPython 3.11（wheelhouse 提供 win_amd64 与
# manylinux_2_28_x86_64 两套 cp311 二进制轮子）。
# 升级任何一个版本后，必须同步更新本文件、wheelhouse/constraints.txt、
# wheelhouse/ 内轮子与根目录 SHA256SUMS.txt，并重新建立产物哈希基线。
